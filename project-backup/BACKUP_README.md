# B3 AI Workshop 雲端備份說明

本目錄保存可重建的完整工作成果：apps_script、data、public、output、source_materials，以及 .build 中的建置與測試腳本。

協作方式：複製此 repository，在 project-backup/ 修改；使用 .build/ 測試腳本驗證；網站成品位於 dist/ 並由 GitHub Pages 發布。Apps Script 的 SPREADSHEET_ID 僅設定在 Script Properties；Web App URL 只放在 public/assets/js/config.js。

本備份不包含帳號密碼、OAuth Secret、API Key 或本機憑證。大型二進位建置產物與重複圖片不納入版本庫，但正式輸出已發布於網站與工作區。
