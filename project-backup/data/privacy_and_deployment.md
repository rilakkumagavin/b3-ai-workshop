# 個資與部署規則

1. 表單不設身分證、電話、住址欄位。伺服器只接受工作表白名單欄位；前後端會拒絕常見身分證、電話與住址格式。自由文字無法保證完整自動辨識，填寫者仍不得輸入敏感個資。
2. 公開 Dashboard 預設只顯示組別，未登記者顯示未分組。講師可在投影前隱藏成果卡；不將姓名當作缺少組別的替代值。
3. Web App URL 只在 public/assets/js/config.js 設定。site/dist/assets/js/config.js 是建置複本，請勿分別維護。執行 site/generate.py 同步，其他程式只讀設定。
4. Google 試算表的一般存取權設為「受限制」，只加入講師、助教需要使用的帳號。不要設定任何知道連結的人可編輯，也不要將試算表發布到網路。Web App 由部署者代為寫入，學員不需要試算表編輯權。
5. 公開表單由伺服器再次檢查 action、payload 型別、欄位白名單、必填、長度、分數與布林值；公式字元以文字儲存。基本驗證不是登入驗證或防濫用機制。
6. Google 密碼、OAuth Secret、API Key、服務帳號私鑰不得提交 GitHub。.gitignore 已排除常見憑證檔；它不會移除已追蹤檔案或歷史中的秘密。部署設定放 Apps Script 指令碼屬性，不寫在公開 JavaScript。
7. 目前未實作 Google 登入。日後若加入，只用於確認使用者身分，不授予學員試算表存取／編輯權，不由前端持有服務帳號金鑰。

## 尚需在線上設定

本次修改的是本機程式與文件，未更改 Google 試算表共用權限，也未部署 Web App。部署前由講師確認共用名單、更新 Web App 版本並填入 config.js。公開 API 的 Dashboard 只回傳投影資料，但自由文字仍需遵守不填敏感個資的規則。
